🏠 Real Estate Housing Price Prediction using Ridge & Lasso Regression
Overview
This project predicts real estate housing prices using Machine Learning regression techniques. The model analyzes various housing features and compares the performance of Ridge Regression and Lasso Regression for accurate price prediction.

Algorithms Used
Ridge Regression
Lasso Regression
Libraries Used
Pandas
NumPy
Matplotlib
Seaborn
Scikit-Learn
Dataset
Housing Price Dataset

Evaluation Metrics
R² Score
Mean Absolute Error (MAE)
Mean Squared Error (MSE)
Root Mean Squared Error (RMSE)
Results
Both Ridge Regression and Lasso Regression models were trained and evaluated on the housing dataset. Model performance was compared using regression metrics to determine the most effective regularization technique for housing price prediction.
